# Robot Sumo

1. ดับเบิลคลิก **Play Robot Sumo.cmd** บนโน้ตบุ๊ก Windows แล้วต่อภาพขึ้นทีวี เบราว์เซอร์จะเปิดที่ http://127.0.0.1:8787
2. ให้มือถือหรือ iPad ทั้งสองเครื่องใช้ Wi‑Fi เดียวกับโน้ตบุ๊ก เลือกเครือข่ายที่ใช้จากหน้า Home หากเครื่องมีหลายเครือข่าย
3. เลือกสนามและ Best of ที่หน้า Home ให้ผู้เล่นสแกน QR ของ Player A และ B จากหน้าจอยให้ปัดขึ้นหรือลงเพื่อเลือกหุ่น แล้วกด **พร้อม** ที่ด้านล่าง เมื่อพร้อมทั้งคู่ เกมจะนับถอยหลัง 5 วินาทีแล้วเริ่มเอง หลังประกาศผล สามารถกดเล่นอีกครั้งหรือกลับหน้าหลักจากจอยได้
4. ค้างหน้าต่างเกมที่เปิดขึ้นไว้จนเล่นเสร็จ ปิดหน้าต่างเพื่อหยุดเกม

ถ้า Windows ขออนุญาตให้ Node.js รับการเชื่อมต่อ ให้เลือกเฉพาะเครือข่ายส่วนตัวที่ใช้งานอยู่ บาง Wi‑Fi แยกอุปกรณ์ออกจากกัน ถ้ามือถือเข้าไม่ได้ ให้ลองใช้เครือข่ายส่วนตัวที่อุปกรณ์สื่อสารกันได้

ทดสอบบนโน้ตบุ๊กเครื่องเดียวได้โดยกด **Keyboard** ที่หน้า Home ผู้เล่น A ใช้ WASD, F, G ผู้เล่น B ใช้ปุ่มลูกศร, K, L กด Keyboard อีกครั้งเพื่อกลับไปใช้จอยมือถือ

ระหว่างเล่น กด **HOME** เพื่อออกจากแมตช์และกลับไปเลือกหุ่น ถ้าจอยหลุด ให้สแกน QR ของฝั่งนั้นบนหน้าหยุดเกมเพื่อเชื่อมต่อใหม่ ใช้ปุ่ม **ซ่อน QR / แสดง QR** เพื่อเปลี่ยนการแสดงโค้ดที่จอเกม

เกมรันด้วย Node.js 20 ขึ้นไป ครั้งแรกตัวเปิดเกมจะดาวน์โหลดไลบรารี WebSocket จึงต้องมีอินเทอร์เน็ต เมื่อติดตั้งแล้วสามารถเล่นผ่าน Wi‑Fi ภายในวงเดียวกันได้ เปิดจากบรรทัดคำสั่งได้ด้วย `npm ci` แล้ว `npm start`

## การเชื่อมต่อจอย

จอยส่งคำสั่งผ่าน WebSocket ที่เปิดค้าง และรับสถานะเกมต่อเนื่อง เมื่อสัญญาณสะดุด เครื่องหลักหยุดคำสั่งเดินเก่าหลัง 175 มิลลิวินาที จอยจะเชื่อมต่อกลับโดยอัตโนมัติและเข้าฝั่งเดิมเมื่อยังเป็นเซสชันเกมเดิม เมื่อเชื่อมต่อกลับ เกมจะนับถอยหลังก่อนเล่นต่อ หากปิดแล้วเปิดโปรแกรมเกมใหม่ ให้สแกน QR ชุดใหม่

ทดสอบระบบจอยและการเชื่อมต่อกลับได้ด้วย `npm test`

## เปิดหน้าเกมบนเครื่องอื่น

บนเครื่องที่รันเกม ให้เปิดหน้า Home แล้วกด **แชร์หน้าเกม** คัดลอกลิงก์ไปเปิดในเบราว์เซอร์ของเครื่องที่อยู่บน Wi‑Fi เดียวกัน ทั้งสองเครื่องจะเห็นและควบคุมแมตช์เดียวกัน ให้เปิดเครื่องที่รันเกมไว้ตลอด หากปิดแล้วเปิดเกมใหม่ ให้คัดลอกลิงก์ใหม่จากหน้า Home

ลิงก์นี้ให้สิทธิ์ควบคุมแมตช์ จึงควรส่งให้คนที่จะดูแลเกม ส่วนผู้เล่นที่ใช้มือถือเป็นจอยให้สแกน QR ของฝั่งตนเองตามเดิม

## เสียง

เพลงและเอฟเฟกต์ออกจากเบราว์เซอร์ที่เปิดหน้าเกม เริ่มเล่นเสียงเมื่อกดปุ่มในเกมครั้งแรก หรือกด **เปิดเสียง** ได้ทั้งหน้าหลักและหน้าแข่ง เกมจะจำการตั้งค่าปิดเสียงไว้ในเบราว์เซอร์ ดูที่มาของเพลงใน **MUSIC-CREDITS.md**
